# 原始资料读取 SOP

> 登记和「内容召回需要回源」时都按本文件走。核心要求：**先真的读到内容，再写台账**；读不通就如实标状态，不假装读过。

## 一、载体类型 → 读取方式

| 载体类型 | 读取方式 | 备注 |
|---|---|---|
| 飞书云文档（docx / wiki） | `lark-cli docs +fetch --doc "<链接或 token>" --doc-format markdown --scope full --as user` | 先看 `--scope outline` 判断篇幅，长文再按 `--keyword` 定位章节；全部走 `--as user` |
| 飞书多维表 | `lark-cli base +table-list` → `+record-list`（`--format ndjson --output <file>` 后本地处理） | 复盘内容可能分散在多条记录，先列字段再决定 |
| 腾讯文档 / 其他在线文档 | 用 WebFetch 打开链接取正文；失败则 `curl -sL --noproxy '*' "<url>"` 取 HTML 再提取正文 | 多数无需登录；需要登录就标「需登录」，不要反复重试 |
| 在线 HTML 报告 | WebFetch；或 `curl -sL --noproxy '*' "<url>" -o /tmp/report.html` 后用脚本剥标签 / Read 读取 | 图表里的数据若只有图片，标「仅摘要」并在备注说明 |
| 本地文件 | Read 工具直接读（md/txt/html/csv）；PDF 用 `workbuddy-pdf`；docx/xlsx/pptx 走对应 Office skill | 绝对路径写进 `本地路径`；注意本机无 PingFang、无微软雅黑等环境限制 |
| 纯文本段落 | 用户给的文字本身就是资料，无需再读 | `载体类型=纯文本段落`、`可读状态=仅本地` |
| 邮件 | 用 Agent Mail 工具按 message_id 取正文与附件 | 附件按上表对应类型处理 |
| 其他 | 先判断能不能拿到正文；拿不到就登记「标题 + 用户描述」，标 `未读取` / `待核验` | 宁可记一条不完整记录，也不要漏掉这份复盘 |

> 本机代理提示：访问 localhost / 内网服务时 `curl` 要加 `--noproxy '*'`，否则会被本机代理拦掉。公网链接正常走代理即可。

## 二、可读状态判定（实测，不靠猜）

| 状态 | 判定条件 |
|---|---|
| 可直接读取 | 成功拿到完整正文 |
| 仅本地 | 只有本地文件/用户粘贴的文字，没有在线链接 |
| 需登录 | 返回登录页、鉴权跳转 |
| 需权限 | 明确返回无权限 / 403 |
| 链接失效 | 404 / 域名不可达 / 文档已删除 |
| 待核验 | 暂时无法验证（如离线、超时） |

`可读状态` 与 `解析状态` 分开填：前者是**链接/文件能不能打开**，后者是**这次实际读到了多少**。

## 三、读完之后做什么

1. 按 `references/extraction-rules.md` 抽成登记卡
2. 一次资料含多个周期/多个项目 → 拆成多张卡
3. 跑 `ledger.mjs register --input cards.json`
4. `解析状态`：读到完整正文 → 已读全文；只读到部分/摘要 → 仅摘要；完全没读到 → 未读取 / 无法访问
5. 读不到的部分在 `备注` 写清楚缺什么，并勾 `待人工确认`

## 四、内容召回时的回源流程

顺序不能反：

1. **先查台账** → `find` 命中记录 → `get --record-id <id>` 拿完整字段
2. **优先用 D 组沉淀内容**（核心策略 / 一句话结论 / 关键数据 / 内容摘要 / 原文摘录）。这是当时读全文留下的成果，比重新抓链接可靠，也更快
3. **以下情况才回源**：
   - 用户问得很细，台账摘要不够
   - `解析状态 ≠ 已读全文`
   - `置信度 < 0.7` 或勾了 `待人工确认`
   - 用户明确要「看原文 / 逐条列 / 核对数字」
4. 回源按第一节对应载体的方式读取；成功后**把新读到的内容补回台账**（`register` 同指纹会更新，不会新增重复记录）
5. 回源失败 → 用已有沉淀回答，并明确说明「台账内容为依据，原文这次没能打开」，附上链接

## 五、失败兜底

- 链接打不开：**仍然登记这条复盘**，把标题、项目、周期、用户描述写进去，`可读状态` 如实填，`解析状态=无法访问`，勾 `待人工确认`。资料存在这件事本身就有检索价值。
- 只有截图/图片无文字层：本机可用 macOS Vision OCR（`pyobjc-framework-Vision`），无 tesseract；识别不了就标「仅摘要」并在备注说明。
- 一份资料极大（> 100 页）：先读目录/大纲定位复盘章节，不要全量塞进上下文；在备注注明「仅抽取 XX 章节」。
- 多次重试仍失败：停止重试，如实报告，不要卡住整个登记任务。
